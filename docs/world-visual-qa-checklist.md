# World Visual QA Checklist

Use the maintained local server at `http://localhost:4000`.
World scenarios are deterministic fixtures for `?sim=1&scenario=<id>` (ids in `claudeville/src/presentation/character-mode/__simfixture__/WorldScenarios.js`, plus `perf-<N>-agents`; an unknown id silently falls back to `mixed-tools`, so check the id).

- **Renderer.** With no flag, Chromium on a hardware GPU runs the WebGPU world; add `&renderer=webgl` or `&renderer=canvas` for the other two backends (`&renderer=webgpu` forces WebGPU, e.g. in Safari; `&postfx=0` is Canvas with no GPU layer). Shift-D's first row and `window.__claudeVilleApp.renderer.worldRendererMode` name the live backend. Plain headless Chromium has no WebGPU adapter and a software WebGL2, so it captures the Canvas world. Every check below is WebGPU unless it names a flag; a visual change is checked on all three.
- **Pinning.** Hour: `__claudeVilleAtmosphere.setHour(h)`. Weather: `setTimelineKnots([{ minute, type }, …])` (types `clear`, `partly-cloudy`, `overcast`, `rain`, `fog`, `storm`; in December–February precipitation falls as snow) pins the timeline itself, so the ground state (wet streets, puddles, snow cover, roofs) integrates it; `setWeather` is a live override only, so use knots for anything the ground should remember. `clear()` resets. Dates (seasons, winter, meteor showers) come from the page clock: Playwright `page.clock.install({ time: new Date('2026-12-15T12:00:00') })` before navigation. Camera: press FREE in the World dock, then `window.cameraSet({ x, y, zoom })` (world px). Reduced motion: emulate `prefers-reduced-motion: reduce`.

## Frozen Renderer Baselines

- Read [`rendering-baselines.md`](rendering-baselines.md) before renderer, trail, PostFX, atmosphere, or material changes.
- Run `npm run world:capture-render-baselines -- --dry-run` after changing the capture matrix.
- Capture the affected manifest IDs in `webgl`, `postfx`, and `canvas` modes (the capture tool has no WebGPU mode; WebGPU is held to WebGL2 by `npm run smoke:webgpu-parity`). Do not compare a forced-FULL PostFX source frame with an adaptive performance level without reporting both values.
- Every performance claim must include Chromium build, GPU/driver, OS, machine label, viewport, DPR, browser zoom, and power state from the capture metadata.
- Review and approve the clear-day, torchlit-night, and action-needed storm north-star frames before broad material or asset production.
- Use `npm run world:benchmark-trails` after trail, camera, or cache changes; manual pan, follow, and director glide must produce zero historical trail-cache repaints.
